# merit badge instructions
The goal of this workshop and these instructions is to get you comfortable with GitHub, use it to set up local environments for testing, and help you learn the skills necessary to complete your badge.





## Tools and Software requirements

* A Chromebook Laptop, Tablet, or some other device that is capable of hitting GitHub.
* a GitHub account, please make one if you do not have one, using this [link](https://github.com/signup?source=form-home-signup).
* Advanced users may want to set up local environments, which is outside the scope of this workshop.


## Environment Setup

We will use GitHub Codespaces. The codespace is an easy way to set up your local environment and write and debug code quickly. It also has the added advantage of being in the cloud; your environment can never break and can always be rebuilt from scratch. Do not worry about the cost, it is [free](https://docs.github.com/en/billing/concepts/product-billing/github-codespaces#free-and-billed-use-by-personal-accounts) as of the writing of this README. 

You should fork the provided list of repos

* [Python](https://github.com/ttallierchio/merit_badge_python_example)
* [Node](https://github.com/ttallierchio/merit_badge_nodejs_example)
* Repo 3

After forking, each repo, you will need to
1. Click the plus on the top bar, it's the fifth button from the left of your account icon
2. Click Create Code Space
3. Pick the repository from the above ones you forked; do not worry about cost, it's free for 120 hours of usage per month.
4. Click Create Codespace.
